# LUMINAE_ARTIFACT_FAMILY_MAP_v0.1.md

## Purpose

This document bridges the **Luminae System Grammar** and the **Species/Civilization Grammar** into actual card design.

It defines how affinity combinations should translate into:

```text
civilization families → artifact families → card names → art direction → Luminary implication
```

This is a **design generator**, not a final card list. Existing Artifacts may be kept, rethemed, renamed, rebalanced, or replaced later.

---

# 1. Core Rule

Artifacts are not random technologies.

They are **civilizational breadcrumbs**: each Artifact should imply what kind of society is forming and what kind of Luminary/destiny that society may eventually reach.

```text
Affinity combo = survival logic
Artifact family = technology expression of that survival logic
```

Examples:

```text
Verdance + Abyss = hidden adaptive life
Artifact families = root vaults, parasite engines, fungal relays, buried biospheres
```

```text
Flare + Radiance = visible expansion through force, signal, and conviction
Artifact families = oath furnaces, solar beacons, crusader engines, edict cannons
```

---

# 2. Tier Logic

## Tier I — Foundational Technologies

Tier I Artifacts should usually be **single-affinity** or very simple concepts.

They represent early civilizational commitments.

Examples:

```text
Flare → ignition, engines, combustion, first weapons
Verdance → roots, seeds, healing, adaptive growth
Continuum → memory, clocks, records, prediction
Abyss → concealment, pressure survival, hidden vaults
Radiance → beacons, law, optics, public signal
```

## Tier II — Hybrid Technologies

Tier II Artifacts should often express **two-affinity combinations**.

They show a civilization discovering a more specific strategy.

Examples:

```text
Verdance + Abyss → hidden biosphere technology
Flare + Continuum → recurring ignition / phoenix-cycle industry
Radiance + Continuum → civic archives / lawful continuity systems
```

## Tier III — Civilization-Defining Technologies

Tier III Artifacts should feel like **society-defining megatechnologies**.

They may be two- or three-affinity, but they should imply a mature civilization path.

Examples:

```text
Verdance + Continuum + Abyss → extinction-cycle seed vault, ancestral root archive
Flare + Radiance + Continuum → dynastic star beacon, solar edict engine
Abyss + Radiance + Continuum → hidden sun observatory, sealed testament engine
```

# 6. Singularity and Artifact Families

Singularity should not define normal Artifact families in the core system.

Do not create standard Singularity Artifacts in the core design.

Singularity may appear as:

```text
wild resource substitution
rare convergence event
visual language for compression or impossible possibility
supporting aesthetic for Encrypt
```

Artifact implication:

```text
Singularity can help buy or enable Artifacts, but should not become a normal Artifact color lane.
```

---

# 7. Blueprint Relationship

Artifacts are **technological objects**.

Blueprints are **strategic patterns / system engines**.

If an idea is primarily:

```text
a reusable rule system
an ongoing modifier
a resource conversion engine
a strategic playstyle framework
```

…it may belong as a Blueprint rather than an Artifact.

Examples:

```text
Artifact: Root Vault
Blueprint: Subterranean Symbiosis

Artifact: Oath-Furnace
Blueprint: Radiant Expansion Doctrine

Artifact: Black Archive
Blueprint: Sealed Knowledge Protocol
```

---

# 8. Practical Card Redesign Use

When designing or auditing an Artifact, ask:

```text
1. What affinity or combo does it express?
2. What survival strategy does that imply?
3. What civilization family would build it?
4. Is it Tier I, II, or III in scope?
5. Does the name imply a technology, not just a vibe?
6. Does the art direction show society-shaping function?
7. Does it point toward a Luminary path without needing to name the Luminary?
8. Is the mechanic better suited to an Artifact or a Blueprint?
```

---

# 9. What Not To Do

Do not make every cool noun into an Artifact.

Do not make Artifacts generic fantasy items without civilizational function.

Do not make all biological Artifacts Verdance by default.

Do not make all hidden/secret Artifacts Abyss by default.

Do not use Singularity as a normal Artifact color.

Do not let Luminary identities force bad Artifact concepts.

Do not redesign all current Artifacts immediately just because this map exists.

---

# 10. Summary

The Artifact Family Map converts affinity grammar into playable card design.

```text
Affinity = survival strategy
Civilization family = who would build this
Artifact family = what technology they would build
Artifact card = one playable expression of that technology
Luminary = destiny implied by the artifact path
Blueprint = ongoing strategic pattern, not the object itself
```

Use this map to generate, audit, rename, retheme, and expand Luminae Artifacts while keeping the game’s science-fantasy identity coherent.
