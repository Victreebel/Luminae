# LUMINAe Future Project Concept Vault v1.0

## Status

**Non-production design archive.** Technology System v2 moved the former Tier
III megastructures into future Manifested Project space. Their concepts and old
artwork are preserved here; none is a currently playable Blueprint unless a
later campaign specification promotes it.

Source and preview art live under:

```text
artifacts/luminae/src/assets/concept-vault/tier3-projects/source/
artifacts/luminae/src/assets/concept-vault/tier3-projects/runtime/
```

These directories must have no production imports and must remain excluded from
production bundles.
