# LUMINAe_ARTIFACT_REPLACEMENT_TABLE_v0.2_SCALE_ENFORCED.md

## Purpose

This document supersedes `LUMINAe_ARTIFACT_REPLACEMENT_TABLE_v0.1.md`. v0.1 improved grammar but failed the engineering-scale ladder. v0.2 preserves the no-mechanics-change constraint while making every artifact obey the tier scale rule: **Tier I = planetary, Tier II = stellar, Tier III = galactic**.

## Hard Scale Rule

| Tier | Required Engineering Scale | What it should feel like |
|---|---|---|
| Tier I | Planetary / orbital / moon-scale | early cosmic civilization infrastructure: worlds, moons, biospheres, atmospheres, oceans, crusts, orbital rings |
| Tier II | Stellar / star-system / heliosphere-scale | stellar harvesting, star lifting, Dyson-adjacent arrays, heliospheric relays, system-wide ecologies |
| Tier III | Galactic / interstellar-network / spiral-arm-scale | galaxy-spanning archives, interstellar transit webs, spiral-arm infrastructure, civilization substrates across many star systems |

## Implementation Scope

Allowed changes: display name, visible flavor/lore, civilization/species lane metadata, artifact-family metadata, art prompt metadata.

Forbidden changes: IDs, costs, tiers, Eminence, mechanical effects, discount behavior, Luminary requirements, Blueprint behavior, tutorial beat order, layout, UI behavior.

## Summary

- Total artifacts covered: **90**
- Scale-correction display-name changes beyond v0.1: **26**
- All Tier I rows now explicitly operate at planetary/orbital/moon scale.
- All Tier II rows now explicitly operate at stellar/star-system/heliosphere scale.
- All Tier III rows now explicitly operate at galactic/interstellar-network/spiral-arm scale.
- This table should be applied literally. Do not infer additional mechanical changes.

## Critical Audit Result

v0.1 should **not** be implemented as-is. It made some Tier I cards sound stellar, some Tier II cards sound planetary, and some Tier III cards sound merely stellar or planetary. v0.2 fixes this by adding an explicit `Engineering Scale` field and rewriting lore/art prompts around scale.
