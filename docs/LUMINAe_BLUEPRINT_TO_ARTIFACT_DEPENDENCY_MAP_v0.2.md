# 1. Core Correction

## The mistake in artifact v0.2

The scale-enforced artifact table treated tier scale too literally:

```text
Tier I = physically planetary object
Tier II = physically stellar / Dyson-like object
Tier III = physically galactic object
```

That made artifacts repetitive and conceptually bloated:

```text
Tier I = world seed / world lattice / planetary cradle
Tier II = solar array / heliostat / Dyson shell / stellar lattice
Tier III = galactic crownwork / galaxy-spanning lattice / universal mandate
```

## Correct rule

```text
Artifact tier describes the civilization capability required to create, power, understand, stabilize, or deploy the artifact.
It does not require the artifact itself to be physically planet-sized, star-sized, or galaxy-sized.
```

An artifact can be small, portable, ritualized, encoded, or component-like.

A lightbulb is small, but it depends on glasswork, vacuum technology, metallurgy, electricity, circuits, manufacturing precision, and infrastructure. Likewise, a Tier III Luminae artifact may be a small object made possible only by galactic-scale civilization.

# 2. Locked Hierarchy

```text
Artifacts = enabling technologies / components / instruments / materials / protocols
Blueprints = assembled civilization-scale projects
Luminaries = destiny endpoints / mythic arrivals
```

## Artifacts should often be

```text
components
instruments
materials
protocols
keys
seeds
interfaces
archives
biotech modules
containment objects
control elements
localized infrastructure nodes
```

## Blueprints should carry the megastructure fantasy

Blueprints are where artifacts combine into larger projects:

```text
Dyson swarms
stellar extraction systems
wormgate networks
galactic archives
spiral-arm ecology meshes
civilizational law engines
migration lattices
void-sector observatories
relic forges
```

## Luminaries should remain distinct

Luminaries should feel like civilization-level destinies, not merely larger Blueprints or stronger Artifacts.

# 3. Scale-as-Capability Ladder

## Tier I — Planetary Capability

A Tier I artifact requires a civilization capable of planetary-scale mastery.

It may imply:

```text
planetary energy grids
orbital industry
biosphere engineering
moon/mineral logistics
climate control
mass manufacturing
planetary archives
planetary governance
mantle/ocean/atmosphere engineering
```

It does **not** need to be a planet-sized object.

Good Tier I forms:

```text
mantle tap valve
climate governor
orbital seed mirror
biofoundry graft
archive monolith
pressure cask
civic beacon core
tidal regulator
blackglass seal
manufacturing die
```

Avoid:

```text
every Tier I artifact being a worldseed, worldroot, world-lattice, or planet-cradle
```

## Tier II — Stellar / Star-System Capability

A Tier II artifact requires mastery of a star system, stellar energy, heliosphere, interplanetary logistics, or multi-world coordination.

It may imply:

```text
star-powered industry
interplanetary supply chains
stellar material extraction
heliosphere weather control
system-wide communication
multi-planet law
star-fed computation
orbital choreography across many worlds
```

It does **not** need to be a Dyson object.

Good Tier II forms:

```text
starlift nozzle
heliopause compass
plasma governor
stellar-memory filament
system treaty key
star-sail vane
magnetosphere latch
fusion choir crystal
solar immunology graft
thermal covenant stone
```

Avoid:

```text
every Tier II artifact being a Dyson shell, solar array, heliostat lattice, stellar collector, or star core
```

## Tier III — Galactic Capability

A Tier III artifact requires galactic-level energy, computation, logistics, coordination, material science, information access, or civilizational infrastructure.

It may imply:

```text
interstellar networks
galactic memory systems
law across many species and systems
spiral-arm routing
dark-sector navigation
galactic ecology management
causality auditing
multi-star resource orchestration
galaxy-scale manufacturing lineage
```

It does **not** need to be galaxy-sized.

Good Tier III forms:

```text
voidline compass
causality audit lens
spiral-arm treaty seed
galactic memory shard
ancestor signal key
dark-sector aperture
ecology substrate code
chronology governor
concordance seal
relic-forge die
```

Avoid:

```text
every Tier III artifact being a galactic lattice, galactic crownwork, galaxy-sized shell, or mandate object
```

# 4. Artifact Form Categories

Every artifact in the next table should receive at least one **Artifact Form**.

| Artifact Form | Meaning | Example object language |
|---|---|---|
| Power Component | Captures, stores, converts, or regulates energy | filament, cell, coil, charge core, thermal sink |
| Control Instrument | Directs or tunes a larger system | governor, compass, lens, regulator, key |
| Material | Civilization-grade substance or substrate | blackglass, living alloy, memory crystal, star-salt |
| Containment | Holds dangerous forces safely | bottle, vault, seal, cask, cage, mantle |
| Interface | Connects domains or systems | aperture, socket, bridge, port, relay |
| Archive | Stores memory, law, ancestry, maps, or prediction | codex, shard, vault, fossil library, chronology seed |
| Protocol | Executable civilization logic | oath, treaty, recursion law, encryption rite, audit rule |
| Biotech Module | Living/adaptive engineered component | spore, graft, organ, seed, symbiont, immune lattice |
| Sensor / Observatory | Detects hidden, distant, or abstract states | omen lens, scanner, horizon probe, dark-sector scope |
| Fabrication Tool | Builds or grows other systems | die, loom, assembler matrix, foundry tool |
| Transit Component | Enables travel, routing, migration, gates | vane, vector key, inertial spine, gate seed |
| Defense / Shielding | Protects, hides, absorbs, or denies access | aegis, veil, decoy, nullifier, shield shell |
| Civic / Signal Object | Coordinates society through visibility, law, or signal | beacon, charter, standard, witness prism |

Hard rule:

```text
A Tier III artifact can be hand-sized if it requires galactic civilization capability to manufacture or interpret.
```

# 5. Blueprint Dependency Grammar

Each Blueprint should define:

```text
Blueprint Name
Project Scale
Affinity Identity
Civilization Type
What It Represents
Required Artifact Component Roles
Optional Artifact Component Roles
What It Assembles
What It Prevents Artifacts From Becoming
```

Blueprints should generally require **3–5 component roles**, not exact card IDs at this stage. Exact artifact mapping comes later in artifact v0.3.

# 9. Artifact v0.3 Design Rules

## Must do

```text
Treat scale as capability, not object size.
Assign every artifact a form category.
Assign every artifact at least one Blueprint family target.
Ensure artifacts vary within the same tier and affinity.
Use Blueprints to carry megastructure/project scale.
Prefer specific component language over generic scale language.
```

## Must avoid

```text
Every Tier I artifact becoming a world seed.
Every Tier II artifact becoming a Dyson/stellar collector.
Every Tier III artifact becoming a galactic lattice/crownwork.
Repeating Crownwork / Lattice / Array / Engine too often.
Making artifacts sound like completed Blueprints.
Making artifacts sound like Luminaries.
Making Singularity a normal Artifact affinity unless explicitly approved later.
```

# 10. Card Art Implications

Artifact card art should depict:

```text
specific object / component / instrument / material / protocol symbol / interface
```

not always:

```text
full planet
full star
full galaxy
complete megastructure
card title baked into the artwork
UI frame baked into the artwork
```

Blueprint card art may depict larger assembled systems.

This preserves visual variety:

```text
Artifact = the part
Blueprint = the machine
Luminary = the destiny
```

# 13. Summary

The corrected design stack is:

```text
Artifacts = enabling components / instruments / materials / protocols
Blueprints = assembled civilizational projects
Luminaries = destiny endpoints
```

Tier scale means:

```text
Tier I = made possible by planetary civilization capability
Tier II = made possible by stellar / star-system civilization capability
Tier III = made possible by galactic civilization capability
```

But artifact size may be:

```text
small
portable
ritualized
encoded
component-sized
localized
modular
```

This blueprint map exists to make artifact v0.3 more diverse, more useful, and less repetitive.
