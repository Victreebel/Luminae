## 1. Variety Axes

Every card is assigned one value per axis. The combination of all five values must be unique within each affinity group (e.g., no two T1 Verdance cards share the same Scale + Shot + Background + Form combination).

### Axis A — Visual Scale
| Code | Label | Description |
|---|---|---|
| MC | Micro | Sub-millimeter to ~10 cm. Crystals, spores, seeds, micro-cells, thread cross-sections. Fills frame at macro magnification. |
| TB | Tabletop | 10 cm – 1 m. Handheld tools, instruments, vessels, coils, wafers, seals. |
| RM | Room | 1 m – 20 m. Apparatus, scaffolds, furnaces, looms, structural components filling a workshop or lab. |
| IN | Installation | 20 m – 1 km. Facility-scale component, visible from outside a building; architectural in presence. |
| PL | Planetary | Habitation/landscape scale. The subject or its installation spans a planetary feature — visible against a horizon or terrain. |
| ST | Stellar | Stellar-structure scale. The subject spans a volume comparable to a solar system feature; star or stellar formation visible as context. |
| GL | Galactic | Galactic-structure scale. The subject operates at cosmic scale; galactic-arm context or deep space visible. |

**Per-tier rules:**
- **T1 (Planetary engineeringScale):** Primarily MC and TB. RM allowed (max 2 per affinity). IN allowed (max 1 per affinity). PL/ST/GL not used.
- **T2 (Star-system engineeringScale):** TB and RM primary. IN allowed (max 2 per affinity). PL allowed (max 1 per affinity). ST/GL not used.
- **T3 (Galactic engineeringScale):** All scales allowed. At least one card per T3 affinity group must be ST or GL. No more than 2 of 4 T3 cards in the same affinity may share PL, ST, or GL together.

The total set must cover all seven scale brackets. Cosmic-scale imagery (PL/ST/GL) is not wrong — the old problem was that *every* card shared it. Variety means the full range co-exists across the 90-card set.

### Axis B — Shot Type
| Code | Label | Description |
|---|---|---|
| MX | Macro close-up | Extreme close-up; no surrounding space context; subject fills ≥ 80% of frame. |
| TA | Tabletop angled | Standard product-shot 3/4 overhead angle; some tabletop or ground surface implied. |
| EL | Eye-level | Front-facing, roughly at eye height; horizon or ground plane visible or implied. |
| XS | Cross-section | Interior cut-through view showing internal structure, layers, channels. |
| WE | Worm's-eye | Looking up at subject from below. |

### Axis C — Background
| Code | Label | Description |
|---|---|---|
| DV | Dark studio void | Pure black or near-black infinity; no objects, no space context. |
| MR | Mineral/rock | Close macro of mineral, stone, soil, ash, or crystal-growth surface. |
| AG | Atmospheric glow | Soft ambient energy or light field; no objects; warm or cool color cast. |
| AE | Abstract energy | Dynamic particle field, plasma interference, or energy distortion; no recognizable objects. |
| NB | Nebula field | Deep-space nebula or stellar cloud; distant stars acceptable; **no planets, no moons, no Earth limb, no galaxy disc.** |
| PB | Planetary backdrop | Planet's surface, horizon, or atmospheric limb; appropriate for PL-scale subjects. |
| SB | Stellar backdrop | Star or stellar formation as contextual element; appropriate for ST-scale subjects. |
| GB | Galactic backdrop | Deep space, galactic-arm structure, or cosmic void; appropriate for GL-scale subjects. |

### Axis D — Subject Form
| Code | Label | Description |
|---|---|---|
| SC | Shard/crystal/mineral | Cut stone, crystal, mineral fragment, prism material. |
| SP | Seed/spore/capsule | Organic capsule, seed pod, spore body, dormant vessel. |
| TI | Tool/instrument | Precision device, control object, compass, nozzle, coil-tool. |
| CF | Coil/filament/thread | Wire, wound coil, woven thread, filament strand. |
| VC | Vessel/containment | Hollow container, cask, flask, crucible, enclosed chamber. |
| TK | Token/seal/wafer | Flat protocol object, stamped disc, etched wafer, key token. |
| LP | Lens/prism/aperture | Optical element, aperture, refractive geometry. |
| OB | Organ/biological | Organic component, graft, tissue section, root/tendril fragment, or biological formation. |
| BF | Baffle/structural | Structural thermal or acoustic component, fin array, channeling unit. |
| KY | Key/lock/activation | Physical or encoded activation key, lock body, cipher plug. |

### Axis E — Palette Temperature
| Code | Label |
|---|---|
| WM | Warm (red/orange/gold dominant) |
| CL | Cool (blue/sapphire/teal dominant) |
| GN | Green (verdance, organic) |
| DK | Dark (black/purple/deep shadow dominant) |
| WG | White/gold (radiance, pearl) |
| MX | Mixed |

## 6. Prompt Construction Rules

Every updated `artPrompt` in `cardLore.ts` encodes:
1. **Shot + Scale** — e.g., "Extreme macro close-up, fills frame" or "Installation-scale eye-level view"
2. **Background** — explicit statement of background type
3. **Subject** — what the specific named object looks like (material, glow, texture)
4. **Palette** — affinity color dominant
5. **Exclusions** — only where historically likely to fail (e.g., no text; no planets for macro shots; no galaxy disc for NB backgrounds)

**Background rules by scale:**
- MC/TB/RM: use DV, MR, AG, or AE — no space context
- IN: may use DV, MR, AG, or AE — no space context
- PL (Planetary scale): use PB (planetary backdrop) — planet surface, horizon, atmospheric limb are correct context
- ST (Stellar scale): use SB (stellar backdrop) — star or stellar formation as context; nebula field acceptable
- GL (Galactic scale): use GB (galactic backdrop) — deep space, galactic arm; galaxy disc as background is acceptable and correct

**"No planets" exclusion only applies to MC/TB/RM/IN scale shots** where a planet would be an incorrect scale intrusion. Do NOT add "no planets" to PL/ST/GL scale prompts where planetary or stellar context is the intended scene.
