## Status

**Historical exact replacement table. Superseded for technology hierarchy and
the listed v1.0 deltas by `LUMINAe_TECHNOLOGY_SYSTEM_v1.0.md`.**

This v0.4 revision preserves v0.3 mechanics and scale-as-capability logic, but changes card-facing presentation so each artifact first states its practical usefulness, then places the mysterious/poetic lore beneath it in italics. Its component-only treatment of Tier III is retained here for history and is no longer canonical.

This document supersedes `LUMINAe_ARTIFACT_REPLACEMENT_TABLE_v0.3_SCALE_AS_CAPABILITY.md`. It uses `LUMINAe_BLUEPRINT_TO_ARTIFACT_DEPENDENCY_MAP_v0.2.md` as the planning anchor.

## Core correction

Tier scale now means **civilization capability required to create, power, interpret, stabilize, or deploy the artifact**, not the physical size of the artifact.

```text
Artifacts = enabling components / instruments / materials / protocols
Blueprints = assembled civilizational projects
Luminaries = destiny endpoints / mythic arrivals
```

A Tier III artifact may be hand-sized if it requires galactic civilization capability to manufacture or interpret.


## Card-facing lore format rule

Each artifact should display usefulness first, mystery second:

```text
Utility: clear practical use sentence.
*Poetic lore: mysterious, evocative sentence beneath it in italics.*
```

The practical use tells the player what the technology does for a civilization. The italicized lore preserves the mythic Luminae tone.

## Implementation scope

Allowed changes: display name, practical use text, visible flavor/lore, civilization/species lane metadata, artifact form metadata, blueprint component role metadata, likely blueprint-family metadata, art prompt metadata.

Forbidden changes: IDs, costs, tiers, Eminence values, mechanical effects, discount behavior, Luminary requirements, Blueprint behavior, tutorial beat order, layout, or UI behavior.

## Summary

- Total artifacts covered: **90**
- Every artifact now receives an `Artifact Form`.
- Every artifact maps to a `Blueprint Component Role`.
- Every artifact maps to one or more likely Blueprint families.
- Every artifact now has a `Practical Use` line for clear utility.
- Existing poetic lore is preserved as italicized text beneath the utility line.
- v0.2 scale-bloat terms like world-lattice, Dyson-everything, galactic crownwork, and mega-lattice language have been reduced.
- Art prompts emphasize specific objects, components, instruments, materials, protocols, keys, archives, and control objects rather than full megastructures.
